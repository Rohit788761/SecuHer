# SecuHer
Women Safety Application 

![Uploading app_logo.png](app_logo.png)

I will provide Emergency Alert System , Map and Defence Tutorials

This project is a safety app that helps people in emergencies.
It has a one-tap alert button that sends an SOS message with your live location on map to your saved contacts.
It also has defence tutorials so users can learn basic self-defence for safety.

Features now:

1. Send emergency alert with location
2. Show live location on Google Maps
3. Defence tutorials for safety
4. Send alert by SMS or call
5. Keep user data safe

Future features to add:

1. AI to detect unsafe areas and warn users
2. Voice command to send SOS
3. Work offline (SMS alert without internet)
4. Shake phone or press button to trigger alert
5. Show incidents reported by other users on map
6. Connect with smartwatch for quick alert
7. Nearby volunteers get alert for help
8. Auto start recording video/audio after alert
9. Safe zone alerts for parents/guardians
10. Multi-language support
